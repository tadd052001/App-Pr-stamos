# App-Pr-stamos

Implementación base de la aplicación con una API REST de tareas para comenzar el desarrollo por etapas.

## Requisitos

- Node.js 18+

## Instalación

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

## Ejecutar tests

```bash
npm test
```

## Endpoints

- `GET /health`
- `GET /api/tasks`
- `POST /api/tasks`
- `PATCH /api/tasks/:id`
- `DELETE /api/tasks/:id`
